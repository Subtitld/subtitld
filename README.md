# Subtitld

Subtitld is a software to create, edit and transcribe subtitles.

## Installation

```bash
pip install subtitld
```

## Requirements

Subtitld uses `ffmpeg` for internal processes.

On Ubuntu/Debian:
```bash
sudo apt install ffmpeg
```

## Usage

```bash
subtitld
```

Or with a file:
```bash
subtitld video.mp4
```
